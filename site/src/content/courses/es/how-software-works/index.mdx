title: Cómo funciona el software
description: "Curso 1: el curso del vocabulario. Cada palabra que vas a oír, explicada con una imagen. No necesitas saber nada antes."

No puedes dirigir lo que no sabes nombrar. En este curso, cada palabra que vas a oír cuando construyes software tiene una explicación sencilla y una imagen: cliente y servidor, frontend y backend, APIs, claves, bases de datos, inicio de sesión, hosting y modelos de IA. Es el curso más largo del Nivel 1, a propósito. En el camino, tu página del Curso 0 recibe datos en vivo de una API y, más adelante, una función que necesita una clave secreta, guardada de forma segura en un servidor.
