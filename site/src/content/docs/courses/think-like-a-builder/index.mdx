Most people open an AI agent and type their whole dream: *"Build me GTA 6, but multiplayer."* It never works, and the reason isn't the AI. **Nobody can build or test everything at once.** This course teaches the method behind every project in the program: **the Builder's Loop**.

> **Idea → problem → smallest useful version → slices → for each slice: "done when" → Claude plans → you approve → Claude builds → you test → real people try it → you decide what's next.**

<CourseOutline />

## The course project

*Your product, slice 1:* pick your idea, write a one-page brief and its slices, ship slice 1 as a clickable prototype, and test it with 3 people.
