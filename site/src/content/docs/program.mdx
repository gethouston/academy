**One path, taken in order.** Each course builds on the one before it and ends with something real that you ship. From Course 2 on, you build **your own product**, one slice at a time, and launch it in the capstone. The whole path takes about **100 hours**, part-time.

:::note[Pilot]
This is an early pilot. Course 0 is complete, and Courses 1 and 2 have their first lessons. The other courses are on the way.
:::
